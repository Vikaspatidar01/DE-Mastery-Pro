# DE Mastery Pro — Data Engineering Academy (PWA)

Free, ad-free, offline-first Data Engineering learning app in **Hinglish** (English technical terms), based on the **Data Engineer Fresher Roadmap 2026**.

Built for BCA / Non-CS / career switchers: **Zero → Job-ready Junior Data Engineer** in 4–5 months.

## Features
- 14 modules, 40+ detailed lessons (SQL → Python → Modeling → ETL → PySpark → AWS → Airflow/dbt → Git/Docker → Projects)
- 30 quizzes with explanations
- 15 interview Q&A
- 4 portfolio project blueprints with checklists
- 16-week roadmap tracker
- Progress, notes, JSON backup (local only)
- Installable PWA (mobile + laptop)
- No ads, no account, no paid API

## Run on laptop
1. Extract the ZIP / open the folder
2. In the folder address bar type `cmd` (Windows) or open terminal
3. Run: `python -m http.server 8000`  (or `py -m http.server 8000`)
4. Open http://localhost:8000 in Chrome/Edge
5. Optional: Install app from browser menu

## Install on phone
1. Deploy folder to any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.)
2. Open the URL in Android Chrome / iOS Safari
3. Add to Home Screen / Install app

Service workers need HTTPS or localhost.

## Stack
Pure HTML + CSS + JS. Content in `content.js`. Progress in `localStorage`. Offline via service worker.

## Honest scope
Substantial curriculum aligned to the roadmap — not a full vendor certification course. Expand lessons/quizzes as you grow. Export backup before clearing browser data.

All the best for your Data Engineering journey!

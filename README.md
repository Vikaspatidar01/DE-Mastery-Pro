## 💻 How to Run on Laptop / Desktop

### Method 1 (Easiest — 1-Click Batch File)
1. Extract the ZIP folder.
2. Double-click **`Run_App_Windows.bat`**.
3. It will automatically start the server and open your default browser to `http://localhost:8000`!

### Method 2 (Python Command)
1. Open terminal or command prompt in the extracted folder.
2. Run:
   ```bash
   python run_server.py
   ```
   *(or `python -m http.server 8000`)*
3. Open `http://localhost:8000` in Google Chrome or Microsoft Edge.

### How to Install as a Desktop App:
- When opened in Chrome or Edge, click the **'Install app'** icon in your browser's address bar (on the right side next to the bookmark star).
- Click **Install**. A dedicated desktop window and shortcut will be created!

## 📱 How to Install on Mobile Phone (Android & iPhone)

Progressive Web Apps require an HTTPS connection (or localhost) for home screen installation.

### 2-Minute Free Hosting (GitHub Pages / Netlify / Vercel):
1. **GitHub Pages (Free):**
   - Create a free GitHub repository (e.g. `de-mastery`).
   - Upload the contents of this folder.
   - Go to **Settings** -> **Pages** -> Set Branch to `main` -> Click **Save**.
   - Your live HTTPS URL will be ready in 60 seconds!
2. **Netlify Drop (10 seconds):**
   - Go to [app.netlify.com/drop](https://app.netlify.com/drop).
   - Drag and drop this folder. Instant live HTTPS link!

### Installing on Phone:
- **Android (Chrome):** Open your URL -> Tap the 3 dots (⋮) -> Tap **"Install app"** or **"Add to Home screen"**.
- **iPhone / iPad (Safari):** Open your URL -> Tap the **Share** button -> Scroll down and tap **"Add to Home Screen"**.

Once installed, the app works **100% offline without internet**!
